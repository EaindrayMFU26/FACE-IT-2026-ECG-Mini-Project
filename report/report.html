Step 2 — ECG filtering with an FIR band-stop filter (first 10 s)

Design. Power-line interference is a narrow-band sinusoid, so a band-stop FIR filter centred on 50 Hz is used. It is designed with the window method (Kaiser window; order chosen by scipy.signal.kaiserord for ≥ 40 dB attenuation with a 2-Hz transition band) and applied forward–backward with filtfilt. A symmetric FIR filter has linear phase; forward–backward filtering cancels its 0.56-s group delay, so the P-QRS-T waves are not shifted.

Step 3 — R-peak detection (first 10 s)

Method — Pan–Tompkins algorithm on the band-stop-filtered ECG: (1) band-pass 5–15 Hz (2nd-order Butterworth, zero phase) to keep the QRS energy; (2) five-point derivative to emphasise the steep QRS slopes; (3) squaring; (4) 150-ms moving-window integration (MWI); (5) adaptive thresholds on the MWI peaks (signal and noise levels updated after every peak, 200-ms refractory period, T-wave rejection within 360 ms, search-back when a beat seems missed). Each R-peak is then located as the maximum of the filtered ECG near the detected QRS.

Two simple plausibility checks make the detector robust to a muscle-noise burst later in the recording (Step 4): (a) a detection that splits one normal RR interval into two is removed (the one that least resembles the median beat), and (b) a beat that matches the median beat template poorly is moved to the best match within ±150 ms. Each beat is labelled Normal, Ectopic (PVC-like) — premature (RR < 80 % of the median), followed by a compensatory pause (> 120 %), abnormal shape (template correlation < 0.5) and > 2× larger — or Low-confidence (noise).

Code 9 · Step 3.1 — R-peak detector: Pan-Tompkins + plausibility checks
 1# Step 3.1 — R-peak detector: Pan-Tompkins + plausibility checks | EaindrayMFU26
 2def pan_tompkins(ecg, fs, pad_s=0.5):
 3    """Pan & Tompkins (1985) QRS detector -> MWI peak indices and intermediate signals."""
 4    pad = int(pad_s * fs)
 5    x = np.pad(ecg, pad, mode="reflect")                        # mirror padding (edge beats)
 6    b, a = signal.butter(2, [5, 15], btype="bandpass", fs=fs)
 7    bp = signal.filtfilt(b, a, x)                                # 1) band-pass 5-15 Hz
 8    der = np.convolve(bp, np.array([1, 2, 0, -2, -1]) * fs / 8, mode="same")  # 2) derivative
 9    sq = der ** 2                                                # 3) squaring
10    w = int(round(0.150 * fs))
11    mwi = np.convolve(sq, np.ones(w) / w, mode="same")           # 4) 150-ms integration
12    cand, _ = signal.find_peaks(mwi, distance=int(0.200 * fs))   # 200-ms refractory period
13    spki, npki = 0.25 * mwi[:2 * fs].max(), 0.5 * mwi[:2 * fs].mean()   # 2-s learning phase
14    thr, qrs, noise, thr_hist = npki + 0.25 * (spki - npki), [], [], []
15    slope = lambda i: np.abs(der[max(0, i - int(0.075 * fs)):i + int(0.075 * fs)]).max()
16    for c in cand:                                               # 5) adaptive thresholds
17        t_wave = bool(qrs) and c - qrs[-1] < 0.36 * fs and slope(c) < 0.5 * slope(qrs[-1])
18        if mwi[c] > thr and not t_wave:
19            if len(qrs) >= 2 and c - qrs[-1] > 1.66 * np.median(np.diff(qrs[-9:])):
20                missed = [n for n in noise if qrs[-1] + 0.2 * fs < n < c - 0.2 * fs
21                          and mwi[n] > 0.5 * thr]                # search-back
22                if missed:
23                    qrs.append(max(missed, key=lambda n: mwi[n]))
24            qrs.append(c); spki = 0.125 * mwi[c] + 0.875 * spki
25        else:
26            noise.append(c); npki = 0.125 * mwi[c] + 0.875 * npki
27        thr = npki + 0.25 * (spki - npki); thr_hist.append((c - pad, thr))
28    qrs = np.array(sorted(qrs)) - pad
29    qrs = qrs[(qrs > -0.08 * fs) & (qrs < len(ecg) + 0.10 * fs)]
30    stages = {k: v[pad:pad + len(ecg)]
31              for k, v in dict(bp=bp, der=der, sq=sq, mwi=mwi).items()}
32    stages["thr"] = np.array(thr_hist)
33    return qrs, stages
34
35def locate_r(ecg, qrs, fs):
36    """R-peak = maximum of the filtered ECG from 100 ms before to 80 ms after each QRS."""
37    r = []
38    for c in qrs:
39        lo, hi = max(0, c - int(0.10 * fs)), min(len(ecg), c + int(0.08 * fs))
40        i = lo + int(np.argmax(ecg[lo:hi]))
41        if not r or i - r[-1] > int(0.02 * fs):          # skip duplicates at the edges
42            r.append(i)
43    return np.array(r)
44
45PRE, POST = int(0.10 * FS), int(0.15 * FS)                       # beat window around R
46
47def detect_r_peaks(ecg, fs):
48    """Pan-Tompkins -> R location -> plausibility checks -> beat labels."""
49    qrs, stages = pan_tompkins(ecg, fs)
50    r = list(locate_r(ecg, qrs, fs))
51    seg = lambda i: ecg[i - PRE:i + POST]
52    inside = lambda i: i - PRE >= 0 and i + POST <= len(ecg)
53    tpl = np.median([seg(i) - np.median(seg(i)) for i in r if inside(i)], axis=0)
54    corr = lambda i: np.corrcoef(seg(i), tpl)[0, 1] if inside(i) else np.nan
55    while len(r) > 2:          # (a) extra detection splitting one normal RR interval
56        med = np.median(np.diff(r))
57        extra = [k for k in range(1, len(r) - 1) if r[k + 1] - r[k - 1] < 1.5 * med]
58        if not extra:
59            break
60        r.pop(min(extra, key=lambda k: np.nan_to_num(corr(r[k]), nan=1.0)))
61    r = np.array(r); moved = np.zeros(len(r), bool)
62    for k, i in enumerate(r):  # (b) re-locate a poorly matching beat (best match +-150 ms)
63        c0 = corr(i)
64        if np.isnan(c0) or c0 >= 0.6:
65            continue
66        js = np.arange(max(PRE, i - int(0.15 * fs)), min(len(ecg) - POST, i + int(0.15 * fs)))
67        cs = np.array([corr(j) for j in js])
68        if cs.max() >= 0.6 and cs.max() - c0 >= 0.1:
69            r[k], moved[k] = js[cs.argmax()], True
70    cc = np.array([corr(i) for i in r])                          # (c) beat labels
71    rr_pre, rr_post = np.r_[np.nan, np.diff(r)] / fs, np.r_[np.diff(r), np.nan] / fs
72    amp = np.array([np.ptp(ecg[max(0, i - PRE):i + POST]) for i in r])
73    med_rr = np.median(np.diff(r)) / fs

Step 5 — ECG feature extraction (every 10 s)

Definitions used.

  • RR interval of beat i: RRi = t(Ri) − t(Ri−1), i.e. the interval that ends at that beat (the same set of intervals as t(Ri+1) − t(Ri)). A beat belongs to the 10-s segment that contains its R-peak.
  • Q point = minimum of the filtered ECG within 40 ms before R (a Q wave lasts < 40 ms); S point = minimum within 80 ms after R; QRS duration = tS − tQ.
  • Reported value per segment = the MEAN of the individual beats in the segment (SD and median are also given). The RR mean uses only normal-to-normal (NN) intervals and the QRS mean uses only normal beats. The ectopic beats, the compensatory-pause intervals that follow them and the low-confidence beat are excluded because they do not describe the normal rhythm (see the table of excluded beats below). All individual beat values are listed in Appendix A.

Step 6 — Machine-learning classification

A. Normal-class data. The RR interval and QRS duration of the 67 individual NN beats from Step 5 are labelled Normal. Individual beat values are used rather than only the six segment means because the arrhythmia samples are also individual beats: both classes are then described in the same unit (one sample = one beat), and the classes are reasonably balanced (67 vs 50 instead of 6 vs 50). The six-segment-mean version is tested as a robustness check (Step 6.6).
B. Arrhythmia-class data. The 50 beats from the assignment table (data/arrhythmia_training_data.csv), labelled Arrhythmia.
C. Model. X = [RR interval, QRS duration], y = [Normal, Arrhythmia]. A Support Vector Machine with an RBF kernel (C = 1, γ = 'scale') is trained after feature standardisation, using a stratified 70 % / 30 % train/test split (random_state = 42). An RBF kernel is chosen because arrhythmic beats lie on both sides of the normal RR range (too short and too long). A single straight boundary in RR cannot separate them; a curved boundary can.

Interpretation of the model performance. The SVM classified all 36 test beats correctly: TN = 21, FP = 0, FN = 0, TP = 15. This gives accuracy, sensitivity (recall), specificity and precision of 100 %, and 5-fold cross-validation agrees (100 %). The result is expected because the two classes do not overlap in feature space. Every arrhythmia sample has a wide QRS (≥ 0.120 s, normal ≤ 0.080 s), and its RR interval is either short (< 0.59 s) or long (> 1.01 s), while the normal RR range is 0.744–0.844 s. The SVM learned a closed region around the normal beats. It also labelled the candidate's three real ectopic beats as Arrhythmia, which is physiologically consistent, although it never saw them.
The perfect score must be read with care: (1) the data set is small and perfectly separable; (2) all normal beats come from one person in one minute, and neighbouring beats are correlated, so a random beat-level split is optimistic; (3) the model has never seen beats with a normal QRS but an unusual RR, such as the sinus beats after the compensatory pauses, which lie on the decision boundary (scores between −0.1 and +0.25) and are classified inconsistently; (4) the arrhythmia values may have been measured with a different QRS method. A real screening model would need many patients, beat types and inter-patient validation.

Interpretation, conclusion and limitations

  • Filtering. The 281-tap FIR band-stop filter (48–52 Hz, zero phase) removes the 50-Hz band (≈ −59 dB) without distorting the ECG. The visible improvement is negligible because the recording contains very little power-line interference.
  • R-peaks. Pan–Tompkins with two plausibility checks detected 13 R-peaks in the first 10 s and 76 in the full minute. 75 of the 76 beats agree with an independent detector on channel 1, and the remaining beat lies in a muscle-noise burst.
  • Heart rhythm. Heart Rate = 76 bpm (75.6 bpm from the mean RR) → Normal. The rhythm is regular apart from three isolated premature, wide, high-amplitude beats with compensatory pauses (premature ventricular complexes). This is a signal-processing exercise, not a medical diagnosis.
  • Features. Segment means: RR 0.782–0.806 s, QRS 0.061–0.068 s. The features are stable and typical of a normal rhythm with narrow QRS complexes.
  • Machine learning. The SVM (RBF) reaches 100 % accuracy, sensitivity, specificity and precision on the test set, because the two classes are clearly separated by QRS duration and RR interval. The estimate is optimistic: the data set is small and comes from one subject, and the model is uncertain for normal-QRS beats with unusual RR intervals.
